Golborne Mosque · A3 poster header
==================================

A header banner for the top of an A3 portrait poster: 297 × 100 mm, the full
width of the page and about its top quarter. The rest of the poster stays free
for its own content (see preview-on-a3.png).

Which file to use
-----------------
golborne-a3-header-print.pdf
    For a printer or a design program (InDesign, Illustrator, Affinity).
    303 × 106 mm: the 297 × 100 mm header plus 3 mm bleed on every side,
    so the colour runs right to the trimmed edge. The title (Cinzel) and the
    address are live text with the fonts embedded, the Arabic calligraphy and
    the symbol are sharp vector, and the patterned background is a 400 dpi
    picture underneath.

golborne-a3-header.png
    For Word, Canva, Publisher or Google Docs. Exactly 297 × 100 mm at
    300 dpi (3509 × 1181 pixels), no bleed. Place it at the very top of an
    A3 page, full width, with the page margins set to zero for that area.

golborne-a3-header.svg
    The editable source (with bleed). The title uses the font Cinzel (free
    from Google Fonts); install it before editing, or the lettering will fall
    back to another font. The Arabic is calligraphy drawn as shapes
    (brand/arabic-name-calligraphy.svg), so it needs no font.

preview-on-a3.png
    How the header sits on an A3 page.

The pattern is the mosque's zellige, from brand/zellige-tile.svg, in the
logo's gold (#e7b22e) on the website's dark grey (#333333).
