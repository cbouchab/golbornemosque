Trustee headshots for the About page (about.html).

1. Save each photo here as a square JPG, at least 320 x 320 pixels,
   named after the trustee, e.g. ahmed-youssfi.jpg.
2. In js/config.js, find "trustees" and set that trustee's photo, e.g.
   { name: "Ahmed Youssfi", role: "Chair", photo: "assets/trustees/ahmed-youssfi.jpg" }

Photos are shown in a circle, so keep the face near the centre.
Please only add a photo with that trustee's permission. Anyone without
a photo is shown with their initials instead.
